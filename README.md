The 36 Stratagems in the Mirror (v3)
Author: Rubyn Vedder

Domain: Strategic Analysis, Game Theory & Systems Engineering

This repository contains the complete, bilingual editions of "The 36 Stratagems in the Mirror" (v3). The work extends traditional Eastern strategy by introducing the mirror-image Yin perspective, a structured analysis checklist based on six core Yin operations, and dynamic feedback loop modeling.

Available Editions
German Edition: Die_36_Strategeme_im_Spiegel_v3_mit_Matrix.pdf

English Edition: The_36_Stratagems_in_the_Mirror_v3_EN_revised_clean.pdf

Core Concepts
Four Levels of Analysis: Core idea, Yang application, Yin recognition/counteraction, and the conscious role switch.

Six Yin Core Operations: Information hygiene, option preservation, cui bono, boundary setting, time control, and escalation control.

Feedback Loop Dynamics: Analysis of what happens when both sides play mirror-aware (escalation, termination, and structure formation).
